# Privacy Notice — SwasthyaScan AI Environment Feature

**Last updated:** 2026-10-27
**Applies to:** The Doctor-Patient Environment feature (Screening Sessions)

---

## Purpose

The Environment feature allows a doctor to create a temporary, private screening session that patients can join using a short join code. Patients submit a chest X-ray and answer a symptom questionnaire. The doctor reviews the AI-assisted analysis and can leave a note for the patient.

This is a **research prototype** — not a certified medical device.

---

## What Is Stored

When a patient joins an Environment and submits a screening:

| Data item | Why stored | Stored as |
|-----------|-----------|-----------|
| Patient pseudonymous ID | Identifies the submission within the session | Plain text (chosen by patient) |
| Chest X-ray image | AI analysis input | Re-encoded PNG, EXIF stripped, random filename |
| Symptom questionnaire answers | Priority scoring input | JSON, linked to pseudonym only |
| AI model output (score, prediction) | Shown to doctor with unverified notice | JSON |
| Grad-CAM++ heatmap | Visual explanation for doctor | Base64 PNG |
| Review priority label + reasons | Workflow support | Text |
| Doctor's notes | Internal clinical annotation | Text |
| Doctor's released guidance note | Shared with patient | Text |

---

## What Is NOT Stored

- Real names, email addresses, phone numbers, or postal addresses
- Any image metadata (EXIF data is stripped on upload by re-encoding)
- IP addresses (used only for rate-limiting; not logged to disk)
- Browser fingerprints, cookies, or tracking identifiers
- Any data from the standalone screening page (that tool stores nothing)

---

## Where Data Is Stored

All data is stored in a **SQLite database file** on the server running SwasthyaScan AI. Image files are stored in a **private uploads directory** that is not accessible via any public URL.

Both locations are excluded from version control (`.gitignore`).

---

## Data Retention

- Default retention: **24 hours** from Environment creation (configurable via `ENVIRONMENT_EXPIRY_HOURS`)
- Automated cleanup runs at startup and every 10 minutes
- The doctor can delete the entire Environment and all associated data at any time using the "Delete Environment & All Data" button
- Deletion removes both database rows and image files immediately

---

## Patient Access

- Patients can view only their own submission status and any guidance note released by the doctor
- Patients cannot access other patients' submissions or the doctor's internal notes
- Patients never see raw AI model scores or pass/fail results

---

## Doctor Access

- Doctors can only access Environments they created (session tokens are environment-scoped)
- Doctor sessions expire after 8 hours

---

## AI Output Disclaimer

- The AI model output is shown to doctors with an "EXPERIMENTAL — not verified" notice while `MODEL_VERIFIED=false`
- The review priority label is generated by experimental prototype rules and is not clinically validated
- No AI output is presented as a diagnosis, triage score, or clinical finding
